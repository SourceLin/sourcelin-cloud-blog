# SQL 初始化说明

本目录提供主线空库初始化脚本。先准备 MySQL，再分别导入业务库和 Nacos 配置库。使用 Seata 时另外导入其事务库。

## 文件说明

- `sourcelin-cloud.sql`：初始化业务表、基础配置、字典、菜单及权限。包含移动端能力、博主申请、公告已读记录、AI 表和默认能力。
- `sourcelin-config.sql`：初始化 Nacos 配置库和 `BLOG_GROUP`，包含网关路由和共享 Redis 配置。
- `sourcelin-seata.sql`：Seata 事务库初始化脚本。

## `sourcelin-cloud.sql` 数据边界

保留的基础数据：

- 系统配置、字典、菜单、角色、部门、岗位、管理员账号和关联关系。
- 定时任务基础定义。
- 博客前台站点基础配置和导航栏。
- 内容举报表结构、后台“内容举报”菜单和 `blog:report:list/query/edit/remove` 权限基础数据。
- 移动端 `mini`、`h5`、`app` 三套能力默认值，评论审核字典及博主申请、移动端和 AI 管理菜单。
- 八项 AI 能力初始配置。开关全部关闭，模型密钥为空。

不写入初始化脚本的数据：

- 文章、分类、标签、评论、说说、树洞、友链等业务内容。
- 点赞、收藏、关注、已读记录、评论机审记录等运行态数据。
- 文件中心记录、访问日志、操作日志、代码生成元数据。

## 维护规则

- 在所属的初始化脚本中维护最终表结构和基础数据。初次导入要求目标库为空，已有环境的切换需先备份并在隔离环境演练。
- 不提交真实环境账号、密码、token、IP、文件访问地址等敏感或环境绑定数据。
- 初始化脚本必须能导入到空库并创建完整表结构。

- `sourcelin-config.sql` 仅保留当前配置。导入后使用部署环境的数据库连接、凭据和文件存储路径。

## 可选 AI 与消息能力

数据库导入完成后，通过服务和能力开关启用可选功能。部署密钥与启用方式见 [AI 与消息部署](../guides/AI_MESSAGE_SETUP.md)。

## Nacos 3.1.1 配置库

初始化前在隔离 MySQL 8.4 实例核对版本、端口、当前账号及库名。三个初始化脚本含固定 USE 语句。配置库采用 [Nacos 3.1.1 官方表结构](https://github.com/alibaba/nacos/blob/3.1.1/distribution/conf/mysql-schema.sql)，首次启动通过控制台设置管理员密码，再配置客户端账号与权限。

升级时保留旧 Nacos 实例及其配置库。在独立的新库初始化，按命名空间导出并导入现有配置，保留 Group、Data ID 和权限映射。新组按本版本示例调整 Redis、OpenFeign 和网关配置键。切换前比对导出清单，回切时恢复旧实例连接参数。
